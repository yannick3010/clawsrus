## Technical Details

Skills are OpenClaw skill definitions (SKILL.md files) that get mounted into the customer's container at provisioning time.

Each skill includes:
- Trigger conditions (what activates the skill)
- Instructions (how to execute)
- Examples (sample interactions)
- Boundaries (what not to do)
